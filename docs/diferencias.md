# Súbelo: diferencias de edición

| Tema | Claude | Codex |
|---|---|---|
| Base | Original fijado en upstream.lock.json | Adaptación Codex instalada y mejoras seleccionadas |
| Activación | Plugin con comandos /subelo:… | Skill $subelo; selección según superficie |
| Configuración de proyecto | Convenciones de Claude del original | AGENTS.md y recursos nativos del host |
| Windows | Requisitos originales; no se promete ejecución nativa | Detecta intérprete y shell disponibles |
| Pruebas | Se separan scripts y estructura de ejecución Claude/Cowork | Se separa copia aislada de descubrimiento en una sesión nueva |
| Autoría | Créditos originales y adaptación Alanmeza.ai | Avisos originales, base instalada y adaptación Alanmeza.ai |

Ármalo conserva seis recorridos en ambas ediciones; Codex lee los dos esquemas de tareas. Chécalo mantiene cinco carriles y oculta toda la línea de evidencia de credenciales. Súbelo conserva producción con autorización posterior al preview en Codex; Claude mantiene sus tres políticas originales, incluido full_auto solo por elección expresa. La variante Cowork pertenece a Súbelo y no se instala en Codex.
