# Súbelo para páginas web

Variante Cowork de Súbelo, adaptada de publish-website. Para carpetas HTML/CSS/JS; no sustituye al recorrido de backends. Importa el paquete subelo-web.plugin en la sección de plugins del host que admita este formato. Aquí solo se ha validado la estructura y el checker; la importación en Cowork queda pendiente.

Para desarrollo con Claude Code: claude --plugin-dir ./claude/cowork-plugin. Entrada namespaced: /subelo-web:subelo-web. Consulta la guía Claude del repositorio para los pasos de uso y requisitos.
